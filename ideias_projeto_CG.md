# Projeto CG: Motor OpenGL 3D

Este projeto académico foi desenvolvido no 3º ano da licenciatura e teve como principal objetivo a criação de um motor gráfico utilizando OpenGL para a simulação de um sistema solar 3D.

## Funcionalidades Principais
- Simulação de órbitas planetárias.
- Aplicação de texturas para maior realismo visual.
- Implementação de iluminação dinâmica.

## Tecnologias Utilizadas
- C++
- OpenGL

## Pontos de Destaque para o CV
Ao adicionar este projeto ao currículo, pode destacar:
- **Competências em Programação Gráfica:** Demonstra conhecimento prático de computação gráfica e renderização 3D.
- **Resolução de Problemas Complexos:** A implementação de órbitas e iluminação envolve desafios matemáticos e algorítmicos.
- **Uso de C++ e OpenGL:** Experiência prática com linguagens e bibliotecas padrão da indústria para gráficos.
